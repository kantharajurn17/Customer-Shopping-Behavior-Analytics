# Customer-Shopping-Behavior-Analytics
End-to-end Customer Shopping Behaviour Analysis using Python, SQL Server, and Power BI. Includes data cleaning, business analysis, KPI calculations, and an interactive dashboard to uncover customer purchasing patterns and generate actionable business insights.
# 📊 Customer Shopping Behavior Analytics



## 1. 📌 Project Overview

This project focuses on analyzing customer shopping behavior to understand purchasing patterns, customer preferences, subscription trends, and sales performance. Python was used for data cleaning and Exploratory Data Analysis (EDA), SQL Server for business analysis and KPI calculations, and Power BI for developing an interactive dashboard.

The objective is to transform raw customer data into meaningful business insights that support data-driven decision-making.

## 2. 📂 Dataset

* **Source:** Kaggle
* **Data Type:** Secondary Data
* **Total Records:** 3,900
* **File Format:** CSV

**Key Columns:**

* Customer ID
* Age
* Gender
* Category
* Purchase Amount (USD)
* Review Rating
* Subscription Status
* Shipping Type
* Season
* Previous Purchases
* Frequency of Purchases

The dataset was used to explore customer demographics, purchasing behavior, and shopping preferences.

## 4. 🔄 Project Workflow

**Step 1: Data Loading**
Imported the Kaggle dataset into Python and examined its structure, columns, and data types.

**Step 2: Data Cleaning**
Used Python and Pandas to inspect missing values, check data quality, and prepare the dataset for analysis.

**Step 3: Exploratory Data Analysis (EDA)**
Explored customer demographics, purchase amounts, ratings, subscription status, and purchasing patterns.

**Step 4: SQL Server Analysis**
Used SQL queries, aggregate functions, and calculations to analyze customer purchasing patterns and derive business metrics.

**Step 5: Power BI Dashboard**
Created an interactive dashboard using KPI cards, charts, and slicers to visualize customer behavior and purchase trends.

**Step 6: Reporting and Presentation**
Prepared a PDF project report and a PowerPoint presentation to communicate the analysis, methodology, and findings.

## 7. Power BI Dashboard

## 6. Key Insights

The project examines customer shopping behavior across several business areas:

* **Customer Behavior:** Understand customer demographics and purchasing patterns.
* **Purchase Analysis:** Compare purchase amounts across product categories and age groups.
* **Subscription Trends:** Explore customer distribution by subscription status.
* **Customer Ratings:** Examine review ratings to understand customer feedback.
* **Business Performance:** Calculate key metrics to support data-driven business decisions.

The findings are explored through Python analysis, SQL queries, and Power BI visualizations.
